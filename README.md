# 二维码生成工具
支持Socks5/VMess/VLess/Trojan/SS协议，可批量生成节点二维码，适配Shadowrocket本地节点解析。

## 功能特点
- 单个/批量生成节点二维码
- 自定义二维码尺寸、颜色、容错级别
- TXT文件导入自动解析节点（每行一个）
- 保留节点原始名称，无额外修改
- 支持批量下载所有节点二维码（ZIP打包）
- 
- ## 使用说明
1. 输入或导入节点（每行一个，支持Socks5/VMess/VLess/Trojan/SS）；
2. 选择自定义配置（尺寸、颜色等，可选）；
3. 点击「生成选中节点二维码」或「批量生成所有节点二维码」；
4. 用Shadowrocket内置扫一扫扫描左侧二维码，所有节点自动添加到本地节点栏。
